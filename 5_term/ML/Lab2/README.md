## Дополнительные задания

## Локальный запуск тестов

Github Classroom дает ограниченное количество минут на тестирование отправок студентов, поэтому чтобы не сжигать их лишний раз, перед отправкой решения на GitHub просьба проверить его локально (иначе потом тестирование будет проходить гораздо дольше). Для этого в репозитории предусмотрены скрипты для разных операционных систем:

### Windows
Есть два варианта запуска:
1. Двойным кликом по файлу `run_tests.bat`
2. Через командную строку:
```cmd
run_tests.bat
```

### Linux/macOS
1. Сделать скрипт исполняемым (только при первом запуске):
```bash
chmod +x run_tests.sh
```
2. Запустить скрипт:
```bash
./run_tests.sh
```

Запускаемые локально тесты ничем не отличаются от тестов, запускаемых на GitHub.

## Сдача лабораторной работы на проверку
Под сдачей задания на проверку понимается загрузка Jupyter-ноутбука с заданием на GitHub. Первичная проверка осуществляется автоматически с помощью тестов в репозитории, дальнейшая проверка осуществляется преподавателем во время защиты лабораторной работы. Лабораторная работа, которая не была защищена, не считается сданной, даже если первичная проверка прошла успешно (тесты завершились без ошибок).

## Вопросы для самоподготовки
1. Ломает ли Feature-engineering над признаками (например, взятие логарифма от каждого элемента признака) "линейность" линейной регрессии?
2. Как можно получить аналитическое решение линейной регрессии?
3. Что такое bias-variance trade-off? Как выглядит bias-variance decomposition? Объяснить вкратце.
4. Что такое переобучение (overfitting) и недообучение (underfitting)? Какие стратегии борьбы с ними существуют?
5. Почему стохастический градиентный спуск способен сойтись? Какие есть преимущества и недостатки SGD по сравнению с обычным градиентным спуском? Как можно улучить SGD (смотри Momentum, RMSProp, Adam)?
