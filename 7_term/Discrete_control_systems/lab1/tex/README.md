# Шаблон отчёта по лабораторной работе

1. Заполните данные титульного листа в `config.tex`.
2. Пишите отчёт в `content.tex`.
3. Складывайте изображения в папку `images`.
4. Собирайте `main.tex` с помощью XeLaTeX.

Рекомендуемая команда для сборки в PowerShell:

```powershell
.\build.ps1
```

Скрипт сам выполняет два запуска XeLaTeX. Все временные файлы (`.aux`, `.log`,
`.out`, `.toc`, `.synctex.gz` и другие) попадают в папку `build`, а готовый PDF
— в `output/pdf/main.pdf`.

Очистить временные файлы перед сборкой можно так:

```powershell
.\build.ps1 -Clean
```

Для сборки через `latexmk` добавлен файл `.latexmkrc` с теми же каталогами.
Если открыть папку шаблона отдельно в VS Code, настройки LaTeX Workshop из
`.vscode/settings.json` автоматически используют `build.ps1`.
