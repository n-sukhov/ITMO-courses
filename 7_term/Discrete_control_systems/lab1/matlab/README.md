# Лабораторная 1, вариант 3

Все модели сохранять в этой папке, рядом со скриптами. Расчёт основан на DCS.pdf: задания на с. 17–18, вариант 3 из таблиц 1–4 на с. 19–22.

## Порядок работы

1. Открыть MATLAB и выбрать текущей папкой `lab1/matlab`.
2. Выполнить `setup_lab1`: появятся переменные для параметров блоков.
3. Оставить существующую `pic8.slx` и самостоятельно собрать ещё три модели по описанию ниже. Сохранить их с указанными именами.
4. В Command Window выполнить по очереди:

   ```matlab
   task1
   task2
   task3
   ```

Каждый скрипт сам вызывает `setup_lab1`. Если MATLAB был закрыт перед сборкой моделей, снова выполнить `setup_lab1`.

Скрипты рассчитаны на запуск в Command Window или кнопкой Run из редактора. Параметры брать из Base Workspace; не создавать одноимённые переменные в Model Workspace.

Время моделирования и решатель скрипты задают автоматически. `task1` и `task2` используют 10 с; гармонический генератор — 160 с, генератор возмущения — 10 с. Длинный интервал гармонического генератора нужен, поскольку период сигнала равен примерно 78.54 с.

После выполнения сохраняются восемь PNG в `../tex/images` и три MAT-файла в `results`. Переносить рисунки вручную не требуется. Модели необходимо сохранить самому перед запуском скриптов.

Скрипты сравнивают выходы Simulink с точным расчётом. Если схема неверна, выполнение остановится с сообщением. После успешного запуска столбец `max_error` показывает максимальное расхождение.

## Общие настройки To Workspace

Во всех моделях добавить блок `To Workspace` на выходной сигнал:

- Save format: `Timeseries`;
- Sample time: `-1`;
- Decimation: `1`;
- Limit data points to last: выключить, либо задать `inf`;
- Variable name: точно как указано для соответствующей модели.

Scope можно подключить параллельно для просмотра; скрипты используют To Workspace.

## 1. pic8.slx — уже существует

Схема:

```text
Step → Sum (+−) → K_FB → Zero-Order Hold → KCO → Integrator → y
        ↑ −                                                │
        └──────────────────────────────────────────────────┘
```

Выход `y` подключить к Scope и To Workspace.

| Блок | Параметры |
|---|---|
| Step | Step time = `0`, Initial value = `0`, Final value = `1` |
| Sum | List of signs = `+-` |
| Gain с именем K_FB | Gain = `1.25`; скрипт меняет значение |
| Zero-Order Hold | Sample time = `T1`, то есть `0.2` |
| Gain с именем KCO | Gain = `KCO`, то есть `4` |
| Integrator | Initial condition = `0` |
| To Workspace с именем Task1Output | Variable name = `task1_y` |

В существующей модели все эти блоки и соединения уже есть. Имена `Step`, `K_FB`, `KCO`, `Integrator`, `Task1Output` сохранить: к ним обращается скрипт.

Скрипт исследует `K_FB = [0 2.5 2.4 1 1.25]`: нейтральная граница, колебательная граница, режим вблизи границы, монотонный процесс, наиболее быстрый процесс. Среди асимптотически устойчивых режимов максимум колебательности не достигается; колебания усиливаются при приближении к `2.5` снизу.

Решатель: fixed-step `ode4`, шаг `0.01`.

## 2. task2_model.slx — одна модель для пяти наборов корней

Объект реализовать блоком `Discrete State-Space`. Он должен выдавать весь вектор состояния `x = [y; y_dot]`, поэтому C в этом блоке равно `eye(2)`.

Схема:

```text
                     ┌──── Gain: -K2 ────┐
                     │                   ↑
                     ↓                   │
              Discrete State-Space ───── x ── Gain: C2 ── y ── To Workspace
```

Выход Gain `-K2` подключить ко входу Discrete State-Space. На вход внешнюю ступеньку не подавать: исследуется свободное движение из начального состояния.

| Параметр Discrete State-Space | Значение поля |
|---|---|
| A | `A2` |
| B | `B2` |
| C | `eye(2)` |
| D | `zeros(2,1)` |
| Initial conditions | `x02` |
| Sample time | `T2` |

Переменные уже определены в `setup_lab1`: `A2 = [1 0.2; 0 1]`, `B2 = [0.02; 0.2]`, `C2 = [1 0]`, `x02 = [1; 0]`.

В обоих блоках Gain выбрать **Multiplication = Matrix(K*u)**:

- обратная связь: Gain = `-K2`;
- выход: Gain = `C2`.

Скрипт `task2` также автоматически задаёт этот режим обоим Gain перед моделированием. При поэлементном умножении обратная связь выдаёт два элемента вместо одного, что вызывает ошибку размерности входа объекта.

To Workspace: Variable name = `task2_y`.

Дополнительный Zero-Order Hold не нужен: `A2`, `B2` уже являются точной дискретизацией непрерывного двойного интегратора с удержанием управления.

| Набор | Желаемые корни | K2 |
|---|---|---|
| 1 | `0.2, 0.8` | `[4 4.6]` |
| 2 | `0.5, -0.8` | `[22.5 9.25]` |
| 3 | `0.1, -0.3` | `[29.25 8.075]` |
| 4 | `0.2i, -0.2i` | `[26 7.4]` |
| 5 | `-0.3+0.7i, -0.3-0.7i` | `[54.5 7.55]` |

Скрипт `task2` сам последовательно устанавливает все пять строк K2. Пять отдельных моделей не нужны.

Решатель: fixed-step `discrete (no continuous states)`, шаг `0.2`.

## 3. task3_harmonic.slx — гармонический генератор

Схема:

```text
Constant: 0 → Discrete State-Space → To Workspace
                                 └→ Scope
```

| Параметр Discrete State-Space | Значение поля |
|---|---|
| A | `G_h` |
| B | `B_h` |
| C | `H_h` |
| D | `0` |
| Initial conditions | `x0_h` |
| Sample time | `T_h` |

Constant: Constant value = `0`, Sample time = `T_h`.

To Workspace: Variable name = `harmonic_y`.

Матрицы и начальное состояние заданы в `setup_lab1`: поворот на угол `0.08*0.2 = 0.016`, `B_h = zeros(2,1)`, `H_h = [1 0]`, `x0_h = [0; 1]`.

Выход: `g(k) = sin(0.08*k*T_h)`. Генерация происходит за счёт начального состояния при нулевом входе.

Решатель: fixed-step `discrete (no continuous states)`, шаг `0.2`.

## 4. task3_disturbance.slx — генератор возмущения

Та же схема `Constant: 0 → Discrete State-Space → To Workspace`, Scope подключить параллельно.

| Параметр Discrete State-Space | Значение поля |
|---|---|
| A | `G_d` |
| B | `B_d` |
| C | `H_d` |
| D | `0` |
| Initial conditions | `x0_d` |
| Sample time | `T_d` |

Constant: Constant value = `0`, Sample time = `T_d`.

To Workspace: Variable name = `disturbance_y`.

Пять состояний объединяют затухающую гармонику и полином: первые два состояния отвечают за `2*exp(-t)*sin(3*t)`, последние три — за `0.1*t^2` и его производные. Начальное состояние `x0_d = [0; 2; 0; 0; 0.2]`, выходная матрица `H_d = [1 0 1 0 0]`.

Выход: `g(k) = 2*exp(-k*T_d)*sin(3*k*T_d) + 0.1*(k*T_d)^2`, `T_d = 0.25`.

Решатель: fixed-step `discrete (no continuous states)`, шаг `0.25`.
